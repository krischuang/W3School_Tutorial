# W3Schools Tutorial Exercises

Personal practice exercises following [W3Schools](https://www.w3schools.com/) tutorials, plus a couple of standalone follow-along projects.

## Contents

```
HTML/               # HTML basics — attributes, elements, editors, worked examples
JavaScript/          # JavaScript fundamentals
JavaScript-ES6/       # ES6 feature-by-feature examples (classes, let/const, spread, Map/Set, promises, modules, ...)
react/               # Standalone React + Vite + TypeScript exercise
```

Each `JavaScript-ES6/*.html` file is a self-contained demo of a single ES6 feature — open it directly in a browser to see it run.

## Status

Learning exercises, not a single cohesive application.
